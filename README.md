# Трезвометр — сайт контроля состояния

Отдельный статичный сайт (не связан с chekhub.ru): расчёт концентрации алкоголя, режим «0,00» для
профессионалов, профиль, дневник, база знаний. Без бэкенда, без аккаунтов — всё считается и хранится
в браузере (`localStorage`).

Рабочее имя и домен — заглушки: меняются в одном файле.

## Структура

```
index.html          калькулятор: «когда 0,00» + обратный расчёт «сколько можно до поездки»
pro.html            режим «0,00» для профессионалов: 3 сценария скорости, запас 20% + 1 час
dnevnik.html        дневник: записи, стандартные дозы за неделю, дни без алкоголя, график, CSV
profil.html         профиль: тело/возраст, скорость метаболизма, модель, сон, калибровка, экспорт
baza-znaniy.html    образовательный раздел (выведение, единицы, сон, риски, мифы, источники)
o-proekte.html      принципы проекта и план развития
politika.html       конфиденциальность: данные не покидают браузер
disclaimer.html     строгий отказ от ответственности
tests.html          автотесты ядра (служебная, закрыта от индексации)
assets/config.js    бренд, домен, контакты, лимиты и умолчания — одна точка правки
assets/engine.js    ЯДРО: граммы → объём распределения → кривая BAC → время до нуля, единицы, напитки

assets/ui.js        помощники, возрастной гейт 18+, тосты, уведомления, файлы
assets/advice.js    рекомендации (вода/еда, сон, недельная норма) и недельная статистика
assets/charts.js    SVG-графики без библиотек (кривая BAC, столбики по дням)

assets/pro.js       логика режима «0,00»
assets/diary.js     логика дневника

assets/tests.js     сами тесты (выполняются в tests.html)

```

## Тесты

```
python -m http.server 8081        # затем http://localhost:8081/tests.html
node tools\node_selftest.js       # 41 проверка формул без браузера, код возврата 1 при провале
python tools\browser_check.py     # 56 проверок в headless Edge: HTML, JS-ошибки, интерактив, тесты
python tools\screenshots.py       # PNG всех страниц в tools\_shots (визуальный контроль)
```

`browser_check.py` и `screenshots.py` поднимают Edge в headless-режиме с **отдельным временным профилем**
и портами 9223/9225 — Chrome пользователя, его профиль и вкладки не затрагиваются.

Проверяются: граммы спирта, объём распределения (Видмарк/Watson), пик и время до 0,00, порог 0,32 ‰,
обратный расчёт, единицы (‰ / % / мг/л), стандартные дозы, хранилище (очистка, экспорт, импорт),
вложенность HTML на всех страницах, отсутствие ошибок JavaScript, работа калькулятора, режима «0,00»,
дневника, профиля и калибровки.

## Перед запуском на реальном домене

1. `assets/config.js` — `name`, `site`, контакты, при необходимости `metrikaId`.
2. Убрать `<meta name="robots" content="noindex,nofollow">` со всех страниц (сейчас стоит специально:
   тестовый домен не должен попасть в индекс).
3. В `sitemap.xml` заменить `https://example.ru` на реальный домен.
4. На главной добавить `<link rel="canonical">` и `og:*` с реальным адресом (заготовка в `<head>`).
5. Публикация — GitHub Pages, как у chekhub: репозиторий, `CNAME` с доменом, `git push`, HTTPS
   включается автоматически.

## Что уже работает

- Расчёт по двум моделям объёма (Видмарк: вес и пол; Watson: плюс рост и возраст), регулируемое время
  всасывания (20–90 мин) и скорость выведения (0,10–0,20 ‰/ч или своя).
- Кривая концентрации с отметкой «сейчас» и порогом прибора; подсказки: пик впереди, вода/еда,
  сон, недельная норма, дни без алкоголя.
- Режим «0,00»: скорость 0,10 ‰/ч, модель Watson, запас 20% + 60 мин, три сценария и вердикт
  «успеваете / не успеваете» к времени допуска.
- Обратный расчёт: сколько чистого спирта успеет выйти к заданному времени.
- Профиль с калибровкой: пары замеров алкотестера без алкоголя между ними → личная скорость выведения.
- Дневник: записи, 7 дней статистики (дозы, дни без алкоголя, часы выше порога, максимум), график,
  экспорт CSV (Excel) и полный бэкап JSON с импортом.
- Единицы: ‰, % BAC, мг/л выдоха; стандартные дозы РФ/ВОЗ/США/Великобритании/Австралии.
- Напоминания: «остановиться пить к 22:30» и «время проверить трезвость» — уведомление браузера, если
  разрешено, иначе сообщение на странице; по умолчанию время берётся из окна сна в профиле.
- 18+, строгий дисклеймер на каждой странице, данные не уходят с устройства.

## В планах (архитектура готова)

- Импорт сна и активности: Apple Health / Google Fit (сейчас окно сна задаётся вручную в профиле).
- Прямая передача замеров с алкотестеров, поддерживающих Web Bluetooth (сейчас — ручной ввод).
- Напоминания браузера «остановитесь к 22:30» и «время контрольной проверки» — **уже работают** на главной
  (`assets/reminders.js`); дальше — повторяющиеся по расписанию и push при закрытой вкладке (нужен service worker).
- PWA-офлайн (`site.webmanifest` есть, service worker — следующим шагом).
- Статьи для SEO: по одной в день, с обложками (правило П2 действует и здесь).

## Формулы и допущения

- граммы спирта = объём(мл) × крепость(%)/100 × 0,789;
- концентрация (г/л) = граммы / Vd, где Vd = вес × 0,68 (муж) / 0,55 (жен) или TBW(Watson) × 0,8;
- кривая: линейный подъём до пика за `peakMinutes`, затем линейное падение `eliminationRate` г/л в час;
- несколько напитков складываются (суперпозиция);
- порог прибора: 0,16 мг/л выдоха ≈ 0,32 г/л крови (коэффициент 2,0 — приближение);
- 1 г/л = 1 ‰ = 0,1 % BAC.

Ошибка модели — до 1,5–2 раз. Сайт не даёт разрешения управлять транспортом; см. `disclaimer.html`.

## Источники

ВОЗ (стандартная доза, пороги низкого риска), NIAAA (standard drink), IARC Monogr. 100E (этанол — группа 1),
КоАП РФ ст. 12.8/12.26 (погрешность 0,16 мг/л и 0,3 г/л), Widmark (1932), Watson et al. (1981).
