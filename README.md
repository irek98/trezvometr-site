# Трезвометр — сайт контроля состояния

Отдельный статичный сайт (не связан с chekhub.ru): расчёт концентрации алкоголя, режим «0,00» для
профессионалов, профиль, дневник, база знаний. Без бэкенда, без аккаунтов — всё считается и хранится
в браузере (`localStorage`).

Домен: **trezvometr.ru** (куплен 07.11.2026 в Timeweb, оплачен до 07.11.2027). Сайт опубликован
на GitHub Pages из репозитория `irek98/trezvometr-site`; адреса в `assets/config.js`, `sitemap.xml`,
canonical и `og:*` уже прописаны — переезд на другой домен делается скриптом `tools/set_domain.py`.

## Что уже работает

- Расчёт по двум моделям объёма (Видмарк: вес и пол; Watson: плюс рост и возраст), регулируемое время
  всасывания (20–90 мин) и скорость выведения (0,10–0,20 ‰/ч или своя).
- Кривая концентрации с отметкой «сейчас» и порогом прибора; подсказки: пик впереди, вода/еда,
  сон, недельная норма, дни без алкоголя.
- Режим «0,00»: скорость 0,10 ‰/ч, модель Watson, запас 20% + 60 мин, три сценария и вердикт
  «успеваете / не успеваете» к времени допуска.
- Обратный расчёт: сколько чистого спирта успеет выйти к заданному времени.
- Профиль с калибровкой: пары замеров алкотестера без алкоголя между ними → личная скорость выведения.
- Дневник: записи, 7 дней статистики (дозы, дни без алкоголя, часы выше порога, максимум), график,
  экспорт CSV (Excel) и полный бэкап JSON с импортом.
- Единицы: ‰, % BAC, мг/л выдоха; стандартные дозы РФ/ВОЗ/США/Великобритании/Австралии.
- Напоминания: «остановиться пить к 22:30» и «время проверить трезвость» — уведомление браузера, если
  разрешено, иначе сообщение на странице; по умолчанию время берётся из окна сна в профиле.
- 18+, строгий дисклеймер на каждой странице, данные не уходят с устройства.

## Формулы и допущения

- граммы спирта = объём(мл) × крепость(%)/100 × 0,789;
- концентрация (г/л) = граммы / Vd, где Vd = вес × 0,68 (муж) / 0,55 (жен) или TBW(Watson) × 0,8;
- кривая: линейный подъём до пика за `peakMinutes`, затем линейное падение `eliminationRate` г/л в час;
- несколько напитков складываются (суперпозиция);
- порог прибора: 0,16 мг/л выдоха ≈ 0,32 г/л крови (коэффициент 2,0 — приближение);
- 1 г/л = 1 ‰ = 0,1 % BAC.

Ошибка модели — до 1,5–2 раз. Сайт не даёт разрешения управлять транспортом; см. `disclaimer.html`.

## Источники

ВОЗ (стандартная доза, пороги низкого риска), NIAAA (standard drink), IARC Monogr. 100E (этанол — группа 1),
КоАП РФ ст. 12.8/12.26 (погрешность 0,16 мг/л и 0,3 г/л), Widmark (1932), Watson et al. (1981).
